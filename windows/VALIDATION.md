## Обнаруженные и исправленные ошибки

- Открытые XML-потоки мешали переносу распакованного EPUB на Windows: потоки закрываются до Directory.Move, проверено повторным импортом.
- Ограничение ширины на body ломало колонную пагинацию epub.js: ширина задаётся внешнему viewer; внутренние columns/gap остаются у движка. Реальные снимки после исправления показывают одну целую страницу.
- SentencePiece не открывал Unicode-путь: токенизаторы передаются как bytes/model_proto. Проверено в каталоге `Читалка`.
- Pretty JSON содержал CR, который разбивал stdio-протокол перевода: используется однострочная сериализация.
- Нативные модальные окна выносятся из WebMessageReceived callback через Dispatcher.Yield, чтобы избежать запрещённой WebView2 reentrancy.
- При восстановлении выделенного фрагмента CFI дополняется повторным поиском text.highlight с before/after после готовности шрифтов. Проверяется фактическая видимость сохранённого слова, а не только наличие локатора.
- Малое окно/дополнительный zoom: навигация получает компактную компоновку, подписи кнопок помощи переносятся целиком.

## Границы доказательств

Это MVP без DRM, интерактивных EPUB, SRS, облачной синхронизации и других форматов. Windows 10, ARM64, экранный диктор и длительные пользовательские сессии отдельно не подтверждены. Качество машинного перевода проверяется пользователем; словарные значения не выбираются автоматически по контексту. Прогресс книги рассчитывается приблизительно по главам и страницам.

Поддержка JSON проверяется отдельно от абсолютной точности переходов между разными EPUB-движками: при повторяющемся одинаковом тексте без достаточного контекста переход может быть неточным. Установщик собственного приложения пока без Authenticode-подписи; это не подпись Android APK.
