# Читалка для Windows

C# / .NET 10 LTS, WPF, WebView2, локальный HTML/CSS/JS-интерфейс и epub.js. Бизнес-логика, SQLite, файлы, резервные копии и вызов перевода — C#. Windows 11 x64. План: [WINDOWS-PLAN](../docs/WINDOWS-PLAN.md).

## Разработка

Нужны .NET 10 SDK и Microsoft Edge WebView2 Evergreen Runtime. Из корня репозитория:

```powershell
dotnet test windows/Chitalka.Tests
dotnet run --project windows/Chitalka.Windows
```

Обычный запуск использует `%LOCALAPPDATA%/Chitalka`. Для изолированной проверки: `--profile C:\path\to\qa-profile`. Параметр `--qa` запускает сценарии в настоящем WPF-окне; используйте только отдельный профиль, поскольку он создаёт учебные записи. Корпус — пять EPUB из `tools/fetch_test_books.py`.

## Перевод

FreeDict/WikDict поставляется с приложением; выберите значение перед сохранением. Предложения переводит локальный CTranslate2 с OPUS-MT int8 и SentencePiece; Python-runtime приватно поставляется в приложении, установка Python пользователем не нужна. Модель устанавливается отдельно через настройки. ML Kit с Android не используется на Windows. Онлайн — MyMemory, с отдельным подтверждением каждого запроса.

Сборка полноценного выпуска, включая runtime, описана в `tools/build.ps1`. Источники и лицензии — `LICENSES.md`.

## Данные

Локальная SQLite с транзакциями и версией схемы. Хранятся исходные EPUB, безопасная распакованная копия, словарь и модель в отдельных каталогах профиля. Удаление из библиотеки сохраняет личные записи, а служебные копии книги удаляет; для восстановления связей добавьте исходный EPUB повторно. Обновление приложения не удаляет профиль.

JSON v1 совместим по схеме с Android: слова, моменты, позиции и история. EPUB и модель переносятся отдельно. CFI Windows дополняется стандартными href/progression/text, Android-локатор без CFI восстанавливается по главе и тексту. Точность перехода для одинаковых повторяющихся фрагментов зависит от сохранённого контекста.

Горячие клавиши: Ctrl+O — EPUB; ←/→ — страницы; H — панели; F11 — весь экран; Esc — карточка/панель; пробел и 1/2/3 — практика. Настройки, источники, резервные копии и загрузка модели доступны через «Настройки и помощь».
