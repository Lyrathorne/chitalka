## Цель и стек

Самостоятельное Windows-приложение: собственные EPUB без DRM, английский → русский, локальные данные, без регистрации и собственного сервера. Функциональный ориентир — Android MVP 1.0.

C# / .NET 10 LTS, WPF-хост, WebView2 и локальный HTML/CSS/JavaScript интерфейс с epub.js. Файлы, SQLite, перевод и резервные копии обслуживает C#. Веб-слой позволяет одинаково оформлять текст EPUB и интерфейс; это уточнение первоначального предложения WPF/XAML. Цель первого выпуска — Windows 11 x64. Windows 10/ARM64 не объявляются проверенными автоматически.

Темы «Бумага» и «Ночь» из концептов. Библиотека, слова, практика, моменты; чтение с ограниченной шириной строки. Мышь, клавиатура, изменение размеров окна и масштаб Windows. Пользователь разрешил публикацию исходников и версий в https://github.com/Lyrathorne/chitalka. Windows-теги: `windows-v…`.

## Критерий готовности

Установить → импортировать EPUB → прочитать и восстановить место → перевести слово/фразу → сохранить слово → создать цитату и заметку → найти их и вернуться к тексту → пройти практику → экспортировать и восстановить данные. Весь сценарий проходит на Windows без собственного сервера; словарь и подготовленная локальная модель работают без сети.

После MVP: синхронизация, SRS, новые форматы, DRM, OCR, macOS/Linux, ARM64. Проверки реального экранного диктора и неподдерживаемых систем не подменяются автоматическими проверками.
