# Читалка 0.7.1 — подписи кнопок без переноса

- Исправлено разбиение «Перевести» на две строки в карточке выделенного текста.
- Ширина действий учитывает размер надписи и системного шрифта. При нехватке места кнопки располагаются в нескольких рядах, сохраняя полные подписи в одну строку.
- Размер шрифта не уменьшается автоматически; область нажатия остаётся не меньше 48 dp.
- Сохранены ручной перевод, цитата и заметка, светлая/тёмная темы и управление моделью из 0.7.0.

Предварительный APK Android 8.0+ с прежней debug-подписью. Устанавливайте поверх предыдущей версии без удаления приложения. Room остаётся v3. Проверки выполнены на эмуляторе; физический телефон отдельно не проверялся.
