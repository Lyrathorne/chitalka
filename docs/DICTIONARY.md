# Локальный словарь

Отдельный встроенный пакет English-Русский FreeDict+WikDict dictionary, Karl Bartel и участники Wiktionary через DBnary, версия 2025.11.23.

- Исходник: https://download.freedict.org/generated/eng-rus/eng-rus.tei
- SHA-256 исходника: `7c48ef3981903361ea90f8ef9a64e58cc7899341d0fb873c2f61198198cba7af`.
- Лицензия данных и производной SQLite-базы: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/legalcode). Титул и лицензия взяты из teiHeader самого файла; общий COPYING каталога не подменяет эту декларацию.
- Преобразование: из TEI извлечены русские переводы с соответствующими английскими пояснениями и частями речи, нормализованы ключи поиска, сформирован индекс SQLite. Не генерируются и не добавляются вымышленные определения.
- Состав: 57 076 нормализованных заголовков, 135 436 записей значений/переводов. Часть исходных заголовков не имеет русских переводов, регистровые дубли объединены в статистике. Это не количество всех английских слов или гарантия покрытия любой книги.
- SQLite: 21 385 216 байт, gzip: 6 917 415 байт. Версия, размер, SHA-256 и атрибуция находятся в `app/src/main/assets/dictionary/manifest.json` и самой базе.

Сборка стандартным Python:

```powershell
rtk proxy python tools/build_dictionary.py --download
```

Без `--download` скрипт использует ранее скачанный `outputs/eng-rus-2025.11.23.tei`. Неожиданное изменение исходника останавливает сборку; обновление требует проверки версии и лицензии. Gzip создаётся с фиксированным mtime. Пакет проверяется SHA-256 до установки, распаковывается во временный файл и открывается только для чтения. Личная Room-база не открывается установщиком пакета и не заменяется при обновлении словаря.

Поиск: точное слово, явно перечисленные неправильные формы, затем кандидаты регулярных форм с проверкой наличия в базе и части речи. Это ограниченные подсказки, не полноценный морфологический анализатор. Точная статья имеет приоритет; омонимы и контекст не разрешаются автоматически. Доступные значения можно выбрать перед сохранением. Сохранённые переводы остаются отдельными личными записями и не меняются при обновлении пакета.

Перевод фразы и отсутствие слова в источнике обслуживает ML Kit с подготовленной моделью. Онлайн-режим остаётся отдельным явным действием.
