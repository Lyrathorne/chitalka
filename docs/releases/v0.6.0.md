# Читалка 0.6.0 — Цитата и Заметка из выделения

- В карточке выделенного текста три действия: «Перевести», «Заметка», «Цитата».
- «Цитата» сохраняет оригинальный текст с переносами между абзацами, автора, название книги и место чтения. Переводчик для этого не нужен.
- «Заметка» открывает редактор перед записью. Отмена оставляет базу без изменений; пустая новая заметка не сохраняется. Для существующей цитаты редактируется её заметка без создания дубля.
- Сохранённое доступно в «Моих моментах» и в закладках книги, с переходом к источнику, редактированием, копированием и системным обменом.
- Повторное сохранение цитаты не стирает её заметку. «Отменить» сразу после сохранения удаляет только неизменённую запись, сохраняя позднее добавленные мысли.
- Исправлено восстановление чтения: если книгу открыли по ссылке на фрагмент, а затем перешли в другую главу, пересоздание экрана восстанавливает текущую главу вместо первоначальной ссылки.

Исходные переносы хранятся в тексте цитаты; локатор остаётся в формате Readium для привязки подсветки. Старые цитаты, заметки и JSON-копии совместимы, схема Room остаётся v3.

Предварительный APK Android 8.0+, подписан прежним debug-ключом. Устанавливайте поверх 0.5.0 без удаления приложения. Проверки — на эмуляторе Android 15; произвольные EPUB и все варианты жестов/оформления на физических телефонах остаются отдельной проверкой.
