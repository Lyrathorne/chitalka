# Источники и сторонние компоненты

- Данные English-Русский FreeDict+WikDict dictionary 2025.11.23 — Karl Bartel и участники Wiktionary через DBnary. Производная SQLite-база: CC BY-SA 3.0. Исходник, изменения, контрольная сумма и сборка: [DICTIONARY.md](DICTIONARY.md).
- Readium Kotlin Toolkit 3.1.2 — BSD-3-Clause; текст лицензии включён в APK в assets/licenses/READIUM-BSD-3.txt. Исходник: https://github.com/readium/kotlin-toolkit/tree/3.1.2.
- Kotlin, Coroutines, AndroidX / Compose / Room / DataStore — Apache-2.0; текст включён в assets/licenses/APACHE-2.0.txt. Поставщики: https://github.com/JetBrains/kotlin, https://github.com/Kotlin/kotlinx.coroutines, https://android.googlesource.com/platform/frameworks/support/.
- Jsoup 1.18.1 — MIT, текст в assets/licenses/JSOUP-MIT.txt; https://jsoup.org/license.
- ML Kit и Google Translate — условия и атрибуция Google: https://developers.google.com/ml-kit/language/translation/translation-terms, https://cloud.google.com/translate/attribution. Официальные значки из архива Google используются без изменения графики, в цветном/белом варианте для двух тем. Они не являются логотипом или знаком одобрения «Читалки».
- MyMemory: https://mymemory.translated.net/terms-and-conditions; это внешний сервис, не встроенный словарь. Перед передачей фрагмента требуется явное подтверждение.
- Системные шрифты Android и системные контурные иконки Material; сторонние файлы шрифтов не добавлены.
- Встроенная демонстрационная книга — специально написанный текст проекта. Пять QA-книг Project Gutenberg хранятся только локально в outputs/corpus и не включаются в APK или репозиторий. Их страницы, хеши и метод получения фиксируются в отчёте проверки.

Лицензии словарных данных и сторонних компонентов не подменяют условия для остального исходного кода приложения. Информация об источниках доступна из меню «Помощь и данные».
