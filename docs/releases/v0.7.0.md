# Читалка 0.7.0 — управление языковой моделью

- На экране «Переводчик» можно удалить загруженную модель EN → RU, затем скачать её снова.
- Перед удалением приложение запрашивает подтверждение. Книги, слова, цитаты, заметки и история повторений сохраняются.
- При удалении закрывается клиент перевода и очищается временный кеш: старый результат больше не выдаётся за новый перевод без модели.
- Добавлены состояния удаления и его ошибки, повтор удаления и ручная проверка состояния.
- Пересоздание экрана после удаления не запускает загрузку автоматически из старого запроса.
- При уходе из чтения закрывается карточка выделения и отменяется её запрос перевода.

На эмуляторе Android 15 проверены реальное удаление, отмена подтверждения, сохранность данных, запуск нового процесса без модели и интернета, цитаты/заметки без переводчика и повторная загрузка настоящего пакета с успешным переводом. Проверка без модели не заменяет полный сценарий чистой установки. Физические телефоны и нехватка места остаются отдельными проверками.

Предварительный APK Android 8.0+, подписан прежним debug-ключом. Устанавливайте поверх 0.6.0, сохранив приложение и его данные. Схема Room остаётся v3.
