# Читалка

Android-приложение для чтения собственных EPUB на английском с переводом на русский, сохранением слов и понравившихся цитат.

## Подтверждено пользователем

- Приоритет английский → русский.
- Удержание выделяет слово; перевод запускается явным нажатием «Перевести» в карточке приложения. Системная панель действий не показывается. Сохранение в личный словарь — отдельным нажатием.
- Карточки и тесты для изучения слов.
- Без собственного сервера; хранение на устройстве.
- Привлекательный лаконичный интерфейс без множества кнопок.
- Закладки понравившихся моментов.
- Разрабатывать приложение и отмечать проверенные пункты в плане Obsidian.
- Если проверки требуют управления экраном, пользователь предпочитает навык agent-desktop; при наличии программных проверок использовать их.

## Рабочие решения прототипа

Kotlin, Compose, Room, Readium 3.1.2 (фиксированная стабильная версия для совместимого прототипа), ML Kit. Android 8.0 / API 26 и выше. EPUB без DRM. По двум пользовательским арт-концептам реализованы переключаемые темы «Бумага» и «Ночь» для приложения и чтения.

## Граница MVP 1.0

Локальный импорт EPUB без DRM, чтение, встроенный словарь с явным выбором значения, машинный перевод с управлением моделью, слова с редактированием, цитаты и заметки с устойчивым возвратом, простая практика с историей и восстановлением сессии, JSON и CSV. Темы «Бумага» и «Ночь», справка и атрибуция. Release APK сохраняет прежний сертификат обновлений и не является отладочным.

Целевой UX: Android-телефоны 320–480 dp. Регистрация и собственный сервер не нужны. Подробная граница и ограничения — docs/MVP.md. Интервалы, тесты знаний, несколько контекстов одного слова как отдельные сущности, TTS, синхронизация, новые форматы и iOS остаются после MVP. Проверки физического телефона, TalkBack и длительных сеансов нельзя считать пройденными по эмулятору.
