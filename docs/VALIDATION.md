# Проверки версии 0.1.0

Дата: 10 ноября 2026 года.

## Успешные проверки

| Проверка | Результат |
| --- | --- |
| `assembleDebug` | APK собран |
| `assembleDebugAndroidTest` | Инструментальные тесты собраны |
| `testDebugUnitTest` | 5 тестов, 0 ошибок |
| `lintDebug` | 0 ошибок, 52 предупреждения |
| AndroidJUnitRunner на Android 15 / API 35 | 4 теста, 0 ошибок, итоговый прогон 34,155 с |

JVM-тесты проверяют допустимый EPUB, запрет обхода каталогов в ZIP, Windows-вариант обхода, неверный mimetype и нормализацию слов с апострофом и дефисом без уничтожения словоформы.

Инструментальные сценарии:

1. Оригинальная демонстрационная книга импортируется; повторный импорт не создаёт дубликат. Цитата с заметкой сохраняется после удаления книги и связывается по хешу при повторном импорте.
2. Readium открывает EPUB; переход во вторую главу сохраняется и восстанавливается после пересоздания Activity.
3. ML Kit загружает языковую модель и выдаёт непустой перевод с кириллицей.
4. Программно выполняется реальное удержание слова в WebView. Полученный перевод сохраняется в Room и появляется на экране словаря; выделенный текст сохраняется в закладку.

## Условия и границы

- Эмулятор Android 15, 1080×1920. Физический телефон не подключался.
- Из-за проблемы Windows JVM с кириллицей в classpath выходные файлы сборки направлены в ASCII-каталог через `chitalkaBuildRoot`; исходники не переносились.
- В промежуточных прогонах загрузка ML Kit завершалась сетевым таймаутом. Обнаружено недоступное IPv6-соединение с сервером модели; для завершения загрузки временно использован IPv4 в эмуляторе. Изменение отменено после проверки. Итоговый прогон выполнен с настоящей скачанной моделью, без заглушки перевода.
- Полный автономный прогон в авиарежиме, убийство процесса, сложные EPUB, длинные выделения и все комбинации настроек ещё не проверены.
- Предупреждения Lint, в том числе строки интерфейса в коде и устаревшие Android API, остаются задачами до стабильного выпуска.
- Сборка GitHub Actions проверяется отдельно после отправки исходников; локальная проверка не доказывает успешность CI.
