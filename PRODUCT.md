# Читалка

Android-приложение для чтения собственных EPUB на английском с переводом на русский, сохранением слов и понравившихся цитат.

## Подтверждено пользователем

- Приоритет английский → русский.
- Перевод по удержанию слова, сохранение в личный словарь.
- Карточки и тесты для изучения слов.
- Без собственного сервера; хранение на устройстве.
- Привлекательный лаконичный интерфейс без множества кнопок.
- Закладки понравившихся моментов.
- Разрабатывать приложение и отмечать проверенные пункты в плане Obsidian.
- Если проверки требуют управления экраном, пользователь предпочитает навык agent-desktop; при наличии программных проверок использовать их.

## Рабочие решения прототипа

Kotlin, Compose, Room, Readium 3.1.2 (фиксированная стабильная версия для совместимого прототипа), ML Kit. Android 8.0 / API 26 и выше. EPUB без DRM. Направление «Бумага» используется предварительно, окончательное оформление пользователем не утверждено.

## Граница текущего этапа

Техническая версия 0.1.0: локальный импорт, чтение, перевод, слова, закладки и простые карточки. Словарные статьи с разными значениями, интервальное повторение, тесты знаний, резервные копии и публичный релиз остаются отдельными этапами. Прототип не считать готовым продуктом.
