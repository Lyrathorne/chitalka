# Читалка 0.4.0

- «Мои моменты»: фильтр по книге, поиск по цитате и заметке, дата и глава (если она есть в локаторе).
- Полная цитата в редакторе с прокруткой; заметка остаётся необязательной.
- «Копировать» и «Поделиться» передают цитату с автором и названием книги. Личная заметка в передаваемый текст не входит. Системный выбор получателя открывается только по нажатию «Поделиться»; приложение ничего не отправляет автоматически.
- Удаление требует подтверждения. Сразу после удаления можно нажать «Отменить».
- Список закладок внутри книги показывает заметки, даты и главу; доступны переход, редактирование, копирование, отправка через системное меню и удаление.
- После просмотра закладки можно вернуться к прежнему месту чтения. Эта возможность сохраняется при пересоздании экрана, например после поворота.
- На экране моментов убраны действия импорта и статус уже готового переводчика. Индикатор активной загрузки сохраняется.

Схема базы не менялась (Room v3). Предварительный APK Android 8.0+ подписан прежним debug-ключом; устанавливайте поверх 0.3.0 без удаления приложения. Проверки — на эмуляторе Android 15. Все варианты выделения нескольких абзацев, восстановления подсветки при смене оформления и физические телефоны ещё требуют проверки.
