# Читалка 0.3.0

Раздел «Практика» теперь сохраняет сессию между запусками приложения.

- Английское слово, необязательная подсказка контекстом, перевод только после «Показать ответ».
- Оценки «Не помню», «Трудно», «Помню». Ответ и переход к следующему слову записываются вместе; повторное нажатие не дублирует историю.
- При возвращении сохраняются текущая карточка, показанный ответ и предыдущие оценки.
- В конце — спокойный итог с числом ответов по каждой оценке и повторным запуском.
- Слова, удалённые из словаря во время сессии, пропускаются. Новые слова добавляются в следующую сессию.
- Оформление сохраняет бумажный фон, оливковые акценты и минимум видимых действий.

Это простые карточки, без интервального расписания и тестов знаний. История ответов входит в JSON-копию, активная сессия остаётся на устройстве и в JSON не переносится.

Схема Room обновляется с 2 до 3 добавлением таблицы сессии. APK подписан прежним debug-ключом: устанавливайте поверх предыдущей версии без удаления приложения. Android 8.0+. Предварительный выпуск; физический телефон на этом этапе не проверялся.
