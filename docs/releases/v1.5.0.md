Исправлен импорт DOCX, состоящих из сканов без текстового слоя. Для таких документов добавлен локальный OCR английского печатного текста. Показывается номер обрабатываемой страницы; изображения обрабатываются по одному. Исходный документ не меняется и не отправляется в сеть.

Windows использует английский OCR-пакет Windows. Android содержит Latin OCR-модель в APK, отдельная загрузка модели не требуется. Результат OCR может содержать ошибки; проверяйте важные места по оригиналу. Сканированные PDF и рукописный текст этим выпуском не добавлены.

Обычные текстовые DOCX продолжают импортироваться прежним способом. Сохраняются перевод, цитаты, заметки, изменение шрифта и место чтения.

Android 8+, versionCode 18.
