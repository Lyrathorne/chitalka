# Резервная копия JSON, версия 1

Формат: `ru.chitalka.app.backup`, `version: 1`. Массивы: `books`, `words`, `bookmarks`, `reviews`. Точные поля и проверки определены в `BackupCodec.kt`; совместимость покрыта тестами.

Копия включает метаданные и SHA-256 книг, локаторы и прогресс, сохранённые переводы и контексты, цитаты с заметками и историю ответов. Файлы EPUB, обложки, модели переводчика, настройки оформления и незавершённая сессия практики не включены. Для восстановления переходов добавьте тот же файл EPUB. Сессия сохраняется на текущем устройстве; её ответы входят в экспортируемую историю.

Ограничения: 16 МиБ, суммарно 100 000 записей. До изменения базы проверяются версия, типы, хеши, даты, локаторы и ссылки истории на слова. Неподдерживаемая версия и повреждённые файлы отклоняются.

Импорт объединяет данные в одной транзакции. Слова совпадают по нормализованному написанию и переводу; различные переводы остаются отдельными. Моменты совпадают по хешу книги и локатору; у более свежей записи сохраняются текст, заметка и вид. История совпадает по слову, времени и оценке. Прогресс обновляется только из более свежей записи. Идентификаторы истории переназначаются на объединённые слова.

С 0.8.0 у элемента `bookmarks` есть необязательное поле `kind`: `BOOKMARK` — позиционная закладка, `QUOTE` — фрагмент текста. При непустой `note` фрагмент отображается в разделе «Заметки». Для старых копий без поля используется `QUOTE`; неизвестные виды отклоняются. Формат остаётся v1 как совместимое расширение, схема Room — v4. Старые версии приложения не сохраняют новый вид при повторном экспорте: перенос позиционных закладок делайте между версиями 0.8.0+.

Перед объединением сохраняется проверенная копия текущей базы. Приложение хранит три последние страховочные копии во внутреннем каталоге; последнюю можно экспортировать. Отмена предпросмотра ничего не меняет. При ошибке записи транзакция откатывается.

CSV: UTF-8 с BOM, CRLF, поля в кавычках, внутренние кавычки удваиваются. Опасные для табличных редакторов начала формул экранируются апострофом. Обратный импорт CSV не поддерживается. Файлы копий выбирает пользователь через системный диалог Android; собственного сервера нет.
