# Читалка 0.8.0 — исправления по отзывам

- Касание центра скрывает и возвращает панели без изменения размера области чтения и повторной разбивки страницы.
- В «Моих моментах» и списке книги три раздела: «Закладки», «Цитаты», «Заметки». «Закладка здесь» сохраняет текущую позицию без выделения текста. Момент с личной заметкой находится в «Заметках», без неё — в «Цитатах».
- Цитата выделена фоном, заметка — подчёркиванием. Нажатие на отмеченный фрагмент или запись списка открывает редактор. Можно менять сохранённый текст и заметку; исходный EPUB и привязка к месту остаются прежними. Переход в книгу — отдельная кнопка редактора.
- Добавлен отдельный онлайн-перевод MyMemory. Перед каждым запросом приложение сообщает об отправке выделенного текста и запрашивает подтверждение. Можно отменить. Офлайн-перевод ML Kit остаётся основным; автоматической отправки текста нет.
- Онлайн-режим предназначен для одного короткого абзаца. У сервиса есть ограничения и дневной лимит; это альтернативный машинный перевод, не гарантия литературного качества. При ошибке сохраняется прежний результат с явным сообщением.
- Перевод можно нажать и исправить до сохранения слова. Указывается источник и факт ручной правки. Длинный ответ прокручивается, вместо обрезания после пяти строк.
- В практике контекст показывает предложение с изучаемым словом и выделяет это слово. Новые контексты не обрезаются посреди произвольного слова.
- Вынесен общий интерфейс провайдера перевода для офлайн- и онлайн-реализаций.

Room обновлён до v4 без удаления данных; старые JSON-копии принимаются. Поле вида закладки включается в новый экспорт. Перед обновлением можно сохранить JSON-копию.

Предварительный APK Android 8.0+ с прежней debug-подписью, для установки поверх предыдущей версии без удаления приложения. Проверки выполняются на эмуляторе Android 15; физический телефон и произвольные EPUB остаются отдельной проверкой.

Условия онлайн-сервиса: [MyMemory](https://mymemory.translated.net/terms-and-conditions). Сервис хранит переданный текст и может передавать его партнёрам; приложение не отправляет ему заметки и словарь.
