Добавлены два режима практики на Android и Windows:

- «Ввод ответа»: напишите перевод, затем проверьте его. Работает и с обратными карточками.
- «Пропущенное слово»: восстановите английское слово в сохранённом контексте книги. Если подходящего контекста нет, приложение сообщает об этом и позволяет открыть карточку.

Проверка учитывает регистр, повторные пробелы, неразрывные пробелы и типографские апострофы/дефисы. Варианты ответа можно хранить в переводе через точку с запятой или с новой строки. Это проверка по сохранённым вариантам, а не оценка смысла произвольной фразы.

Ответ раскрывается после проверки. Оценка «Не помню / Трудно / Помню» сохраняется отдельно и влияет на существующее расписание повторения. Книги и учебные данные при обновлении сохраняются.

Проверено: Android-эмулятор API 35 и настоящее окно WPF/WebView2. Физический телефон не проверен.

Windows 11 x64. EXE — установщик; ZIP — portable-сборка.
