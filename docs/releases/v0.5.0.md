# Читалка 0.5.0 — Бумага и Ночь

Две темы по предоставленным арт-концептам:

- «Бумага»: кремовый фон, тёмный книжный текст и оливковые акценты; крупная первая книга и сетка остальных обложек.
- «Ночь»: почти чёрный зелёный фон, тёплый светлый текст и светлый шалфейный акцент; вертикальный список книг.
- Один выбор для библиотеки, словаря, практики, резервных копий, загрузки модели и Readium. Сохраняется в DataStore и применяется при запуске приложения.
- Переключение: меню с тремя точками → «Оформление»; из книги: Aa → «Оформление».
- Контурные иконки, тонкая линия выбранной вкладки, небольшие скругления кнопок и книжная типографика.
- Поиск раскрывается через меню → «Поиск». Действия удаления книги перенесены в меню строки/обложки.
- Компактная карточка перевода со стрелкой к выделению, согласованные цвета диалогов и системных панелей. Перевод по-прежнему запускается только по нажатию.
- Название главы сверху и процент чтения снизу. Контекст слова выделяет искомое слово акцентом.

Обложки берутся из EPUB. При отсутствии обложки используется текстовый вариант с названием и автором; иллюстрации из арт-концептов не подменяют содержимое книг.

Настройка темы хранится на устройстве и не включается в JSON-копию. База Room остаётся v3. APK подписан прежним debug-ключом, устанавливается поверх 0.4.0 без удаления данных. Предварительная версия Android 8.0+; проверки проведены на Android 15 в эмуляторе.
