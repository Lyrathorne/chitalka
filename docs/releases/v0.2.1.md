# Читалка 0.2.1

- Удержание слова теперь показывает только компактную карточку приложения: «Перевести» и «В закладки». Автоматический перевод отключён.
- Системная панель над выделением удалена. Маркеры диапазона остаются, чтобы выделять фразы.
- Перевод появляется в той же карточке только после нажатия. При смене выделения старый результат убирается, незавершённый запрос отменяется.
- Карточка закрывается касанием вне неё и кнопкой «Назад». Она располагается над или под фрагментом, в пределах страницы без перекрытия верхней панели.
- Оливковая подсветка и шрифт слова приближены к предоставленному концепту.
- Меню слова в словаре: редактирование, «К месту в книге», удаление с подтверждением. При удалённом EPUB остаётся контекст и объяснение, как восстановить переход.
- Поиск работает по английскому слову и переводу, предусмотрено пустое состояние поиска.

Android 8.0+, предварительный APK с прежним debug-ключом. Устанавливайте поверх 0.2.0 без удаления приложения. Обновление не меняет схему базы. Проверки проведены на эмуляторе Android 15; физический телефон отдельно не проверен.
