# Читалка 0.8.1 — масштаб текста и видимость заметок

- Исправлены единицы масштаба Readium: 110% передаётся как коэффициент 1,1. Масштабирование WebView изменяет и текст EPUB с фиксированным размером шрифта; выбор сохраняется.
- Подчёркивания заметок защищены от CSS книги, обнуляющего рамки элементов. Цитаты по-прежнему выделяются фоном.
- Действия редактора переносятся целыми кнопками в новые строки. Все действия доступны с прокруткой; клавиатура не закрывает кнопку сохранения.
- В настройках чтения виден номер установленной версии.

Проверен именно публичный APK 0.8.0: воспроизведены неизменный размер букв при фиксированном шрифте EPUB и исчезновение линии заметки при сбросе рамок стилями книги. На обычном тестовом EPUB сохранение и подчеркивания в 0.8.0 работают; точная причина на пользовательской книге требует проверки её файла.

Android 8.0+. Предварительный APK с прежней debug-подписью для установки поверх 0.8.0. База Room v4 не меняется; удалять приложение не требуется. Проверки выполняются на эмуляторе Android 15, физический телефон отдельно не проверен.
