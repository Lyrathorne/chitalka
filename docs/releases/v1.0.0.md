# Читалка 1.0.0 — первый MVP

- Встроенный словарь FreeDict/WikDict: 57 076 заголовков, 135 436 вариантов. Словарные статьи доступны без сети и языковой модели; поддержаны точные формы и ограниченные подсказки начальной формы.
- При нескольких переводах нужен явный выбор. Можно открыть доступные значения с пояснениями, перейти к Google Translate или вручную исправить результат. Полнота и точность источника не гарантируются.
- Сохранены отдельный MyMemory по подтверждению, загрузка/удаление модели ML Kit и офлайн-перевод после её подготовки.
- Основной сценарий включает EPUB, восстановление чтения, слова и контекст, цитаты и заметки, простую практику с историей, JSON и CSV. Две темы соответствуют пользовательским концептам.
- Добавлены справка, сведения об источниках и приватности, тексты основных лицензий офлайн и официальная атрибуция Google Translate рядом с результатами.
- Авторские скрипты, обработчики событий и внешние ресурсы EPUB ограничены. Файлы книг остаются неизменными; интерактивные EPUB в MVP не входят.
- Выпускается подписанный release APK без debuggable. Сертификат прежний: можно устанавливать поверх 0.8.1 без удаления приложения. Room остаётся v4; личные данные не заменяются словарным пакетом.

Проверки: чистый старт без сети/модели, системный импорт EPUB, выбор и сохранение слова, цитата/заметка, ответ в практике, экспорт через системный диалог, восстановление на другой пустой установке, повторный импорт EPUB и восстановление главы/отметок после force-stop. Проверены пять настоящих EPUB и обновление поверх 0.8.1 со сравнением данных.

Android 8.0+. Проверки выполнены на эмуляторе Android 15. Физический телефон, TalkBack и длительные сеансы чтения требуют отдельного подтверждения. Интервальное повторение, тесты знаний, PDF/OCR/FB2/TXT, синхронизация и iOS не входят в первый MVP.
