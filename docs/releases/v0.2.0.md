# Читалка 0.2.0

- «Меню библиотеки» → «Копии и перенос»: экспорт и восстановление JSON, экспорт слов в CSV.
- Перед восстановлением показывается состав копии. Данные объединяются; перед записью автоматически сохраняется страховочная копия. Последние три копии остаются внутри приложения, последнюю можно экспортировать.
- Сохраняются слова, контексты, история ответов, цитаты, заметки и место чтения. Книги EPUB и модели переводчика не входят в JSON. Повторное добавление того же EPUB восстанавливает связи по хешу.
- Касание слова открывает редактирование перевода и контекста.
- Повторный импорт книги предлагает открыть существующую запись. В библиотеке появились сортировки по названию, автору и недавнему чтению.
- База Room обновляется с версии 1 до 2 с сохранением данных.

Устанавливайте APK поверх 0.1.1 без удаления приложения: используется прежний локальный debug-ключ. Это предварительная версия Android 8.0+. Настройки оформления не переносятся в JSON; CSV предназначен для экспорта, восстановление выполняется из JSON. Копии содержат личные заметки и не шифруются приложением.

Проверки: 15 JVM-тестов; Android-тесты миграции, объединения, отката транзакции, системного выбора файлов, редактирования и чтения. Физический телефон в этом этапе не проверялся.
