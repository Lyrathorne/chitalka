# Читалка для Windows — MVP 1.0.0

**Windows 11 x64.** C# / .NET 10 LTS, WPF и WebView2. Самостоятельное локальное приложение, без регистрации и собственного сервера.

## Установка

- `chitalka-windows-1.0.0-x64-setup.exe` — обычный установщик без прав администратора.
- `chitalka-windows-1.0.0-x64.zip` — распакуйте целиком и запустите `Chitalka.exe`.
- `SHA256SUMS.txt` — контрольные суммы файлов выпуска.

.NET и приватный runtime переводчика входят в поставку: Python и SDK устанавливать не нужно. Нужен Microsoft Edge WebView2 Runtime; установщик обнаруживает имеющийся runtime, при его отсутствии запускает официальный загрузчик Microsoft (для первой установки понадобится интернет).

## Возможности

EPUB без DRM, библиотека с обложками/поиском/сортировкой, продолжение чтения, оглавление, страницы и прокрутка, настройка шрифта/интервала/ширины. Две темы «Бумага» и «Ночь», полноэкранный режим и клавиатура.

Выделение показывает собственную карточку. Перевод запускается только кнопкой. Встроен FreeDict/WikDict на 57 076 заглавных слов с выбором значения и сохранением контекста. Локальные слова, простая практика с историей и восстановлением сессии.

Закладки, цитаты фоном, заметки подчёркиванием; редактирование, копирование без личной заметки и возврат к тексту. JSON v1 совместим с Android, CSV защищён от формул. При восстановлении — проверка и защитная копия. Исходные EPUB нужно переносить отдельно.

## Перевод предложений

В настройках нажмите «Загрузить модель»: OPUS-MT EN→RU int8, около 69 МБ. Загрузка показывает прогресс и допускает отмену; пакет проверяется SHA-256. Затем перевод работает на CPU без отправки текста в сеть.

Альтернатива для автономной установки: скачайте `chitalka-model-en-ru-v1.zip` из [выпуска модели](https://github.com/Lyrathorne/chitalka/releases/tag/windows-model-v1) и выберите «Установить из ZIP». Отдельная кнопка онлайн-перевода MyMemory требует подтверждения отправки каждого фрагмента. Машинный перевод может ошибаться; результат можно исправить.

## Данные и ограничения

Профиль: `%LOCALAPPDATA%/Chitalka`. Повторная установка сохраняет данные. Экспорт JSON не содержит книги, модель, оформление и активную сессию практики. Лицензии и источники доступны офлайн в помощи и в поставке.

Windows 10, ARM64 и экранный диктор отдельно не подтверждены. Первый MVP: без DRM, SRS, синхронизации и PDF/FB2/TXT/OCR. Установщик приложения пока без Authenticode-подписи; WebView2-загрузчик — оригинальный подписанный Microsoft файл.

Проверки и их точные границы: [windows/VALIDATION.md](https://github.com/Lyrathorne/chitalka/blob/codex/initial-prototype/windows/VALIDATION.md).
