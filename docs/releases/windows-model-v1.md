# Офлайн-модель EN→RU для Читалки Windows

OPUS-MT EN→RU (`opus-2020-02-11`), Helsinki-NLP / OPUS; преобразована CTranslate2 4.6.3 OpusMTConverter, int8. Работает локально на CPU. Качество машинного перевода требует проверки пользователем.

Источник: https://object.pouta.csc.fi/OPUS-MT-models/en-ru/opus-2020-02-11.zip

Лицензия из исходного архива: **CC BY 4.0**. В пакет сохранены README и LICENSE; source.spm/target.spm не изменены. Для распаковки и запуска используется Windows-приложение Читалка с собственным CTranslate2-runtime.

Размер ZIP: 72 386 862 байта. SHA-256:
`70b9e348ba7bc195eb89d7be980dff0e0b3c7e92c6b4f36363b894db30ce24a6`.

Загрузите модель через «Настройки и помощь» → «Загрузить модель» или сохраните ZIP и выберите «Установить из ZIP». Библиотека и личные данные не входят в пакет модели.
