# Читалка для Windows

Desktop-перенос Android MVP 1.0 на C#. Windows 11 x64; WPF-хост и локальный интерфейс в WebView2; epub.js для книги. Без сервера и регистрации. EN→RU, EPUB без DRM, словарь, локальный машинный перевод, явный онлайн-перевод, слова, практика, закладки/цитаты/заметки, Android JSON и CSV.

Сохранить темы из ../DESIGN.md. Read: текст книги, Operate: библиотека/слова/практика. Слева спокойная навигация, в чтении скрыта; один главный акцент на экране. Минимальная ширина окна 800 DIP, полноценная клавиатура, масштабирование Windows. Обложки только из EPUB; при отсутствии — типографическая обложка. Системный serif разрешён исходным визуальным направлением, служебный Segoe UI. Никаких серверных ключей и автоматической отправки выделений.

Личные данные в LocalAppData/Chitalka; отдельно неизменяемый словарь и загружаемая модель. Удаление книги не удаляет учебные данные. EPUB недоверенный: изолированные ресурсы, скрипты и внешние запросы запрещены. Только доверенная страница приложения получает команды C#.
