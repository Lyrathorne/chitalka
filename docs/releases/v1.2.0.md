Изменения по отзывам пользователя:

- Полки: создание, фильтр библиотеки, добавление одной книги на несколько полок через меню «На полку». Полки хранятся локально и пока не входят в JSON-экспорт.
- Быстрый свайп вниз в книге ставит закладку. Список закладок остаётся в верхней панели.
- Разрешение MyMemory запоминается после первого согласия; его можно сбросить в помощи. Перевод отправляется только по кнопке «Онлайн».
- Слово сохраняется без обязательного выбора значения; остальные значения доступны в словаре кнопкой «Другие значения».
- Читаемая книга остаётся среди обложек и показывается сверху. Размер обложек ограничен на широких экранах.
- Убрано ограничение исходной книги в 100 МБ. Защита распаковки и ограничения XML/PDF остаются.

Android 8+, версия 1.2.0 / code 15. Качество MyMemory зависит от сервиса; автоматический выбор значения по контексту не заявляется.
