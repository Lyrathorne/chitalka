Добавлены PDF с текстовым слоем, DOCX, FB2, FB2.ZIP и TXT вместе с EPUB. Импорт через «+» или перетаскивание. Текстовый режим поддерживает перевод, шрифт, обе темы, слова, цитаты, заметки и прогресс.

Сканам PDF требуется предварительный OCR; защищённые PDF и старый DOC не поддерживаются. Исходная сложная вёрстка и изображения не переносятся. [Форматы и ограничения](https://github.com/Lyrathorne/chitalka/blob/codex/initial-prototype/docs/FORMATS.md).

Windows 11 x64. Setup обновляет установленную версию, ZIP предназначен для portable-запуска. Локальный машинный переводчик загружается отдельно; установленная модель сохраняется. Проверены 34 теста Core и реальное окно WPF/WebView2 с новыми форматами.
