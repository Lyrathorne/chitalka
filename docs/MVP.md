# MVP 1.0

Граница первого выпуска: Android 8.0+, собственные EPUB без DRM, английский → русский, локальное хранение, без регистрации и собственного backend.

Обязательный сценарий: системный выбор EPUB → библиотека → чтение с восстановлением места → явный перевод слова → выбор значения/ручная правка → сохранение с контекстом → практика → экспорт JSON → восстановление и повторное добавление исходного EPUB. Отдельно: цитата, заметка, закладка позиции и переход к ним.

## Что входит

- Темы «Бумага» и «Ночь» по пользовательским концептам, оглавление, страницы, размер текста и скрываемое управление.
- Встроенный словарь FreeDict/WikDict, выбор доступного значения, подсказки начальной формы. Несколько вариантов не выбираются автоматически по контексту.
- ML Kit / Google Translate после первоначальной загрузки модели; управление её состоянием и удалением. MyMemory — только отдельной кнопкой и после подтверждения каждого запроса.
- Личные слова с редактированием, контекстом и ссылкой на книгу; простые карточки с историей и восстановлением незавершённой сессии.
- Цитаты фоном, заметки линией; редактирование, копирование/обмен без личной заметки, фильтры и возврат к фрагменту.
- JSON с проверкой и объединением, страховочная копия, CSV. Удаление книги сохраняет учебные данные и моменты; тот же EPUB восстанавливает переходы по SHA-256.
- Справка, информация об источниках/хранении, тексты основных лицензий офлайн, официальная атрибуция Google Translate возле результатов.
- Release APK без флага debuggable, с прежним сертификатом для обновления поверх предварительных версий.

## Что остаётся после MVP

Интервальное повторение, автосохранение, тесты с вариантами/вводом ответа, несколько встреч одного слова как отдельная сущность, автоматическое определение значения по контексту, TTS, напоминания, синхронизация, iOS, PDF/OCR/FB2/TXT. Это не препятствует критерию MVP из раздела 13 исходного плана. Невыполненные пункты этих направлений сохраняются открытыми, а не отмечаются готовыми.

## Ограничения

EPUB: до 100 МБ, распакованные данные до 300 МБ, до 10 000 файлов, HTML/SVG-глава до 8 МБ. Авторские скрипты, обработчики событий, встроенные фреймы и внешние ресурсы книги ограничены. Интерактивные EPUB, удалённые изображения/шрифты и сложная мультимедийная разметка не являются целевым сценарием.

Словарь не покрывает все словоформы и значения. На пяти QA-книгах точный поиск покрывает 81–83% словоупотреблений; подсказки форм учитываются отдельно. Счёт включает текст EPUB, в том числе оглавления и служебные страницы Project Gutenberg. Это не метрика точности переводов. Машинный перевод требует проверки пользователем.

JSON не содержит книги, языковую модель, оформление и активную сессию практики. Перед удалением приложения или переносом нужно сохранить JSON вне приложения и исходные EPUB.

Проверки эмулятора, подписи и CI фиксируются в VALIDATION.md. Проверка физического телефона, TalkBack и длительных реальных сеансов отмечается отдельно; её нельзя считать выполненной по одним эмуляторным тестам.
